# 字体、音频与资源交付

## 文字分工

包内的 Silkscreen Regular 与 Bold 用于拉丁标题、数字与短标签。Noto Sans SC 是包含字重轴的中文字体，用于中文标题、正文和详细信息。两者的原始授权与下载来源随文件提供，来源清单位于 [fonts/sources.json](../assets/fonts/sources.json)。

像素拉丁字体在接近设计像素节奏的尺寸上使用。长句与中文按主题中的正文尺寸和行高起步，实际设备上检查，不用缩小正文补偿布局拥挤。标签和数字对齐，重要文字不依赖低对比暗灰。字形和对比检查属于最终验收。

品牌名与策划术语可任意变化。支持所有需要的字符与标点，包括中英文混排、全角符号、数字和本地化文本。用于图片的像素字标应有可访问文本，不能因为蓝图只含少量字母而漏字。

Web 的 `@font-face` 路径相对实际 CSS 文件；原生引擎导入字体或生成覆盖所需字符的字体图集。验证字体真的加载成功以及实际字形显示，不能只检查文件名或 CSS 声明。字体可转为 WOFF2 或按文本裁剪，但保留授权、字符覆盖和必要的动态文本回退。

将实际文案（含动态状态与标点）保存为 UTF-8 文本，运行 `node scripts/validate-bundle.mjs --text <文案.txt>` 检查包内字体的 cmap 覆盖。检查指定字体时加 `--font NotoSansSC.ttf` 等文件名。默认检查三份字体合计能否提供字形；实际排版还要验证各控件的字体链。

旋转箭头、星形、控制键等功能图标采用本地 SVG、CSS 几何或像素蓝图，并提供文本标签或可访问名称。包内 Noto Sans SC 缺少 `↻`（U+21BB）和 `✦`（U+2726）；浏览器可能用系统字体补齐。`document.fonts.check()` 只检查加载状态，不能证明每个字符来自指定字体。其他语言或特殊字符按实际文案增加合适的本地字体与授权。

## 声音跟随材质和事件

整体声音保持短、清楚、留有空隙。灰阶世界的静态氛围可以低频、薄层、缓慢变化；高饱和动作对应更明确的瞬态。

| 语义 | 声音方向 |
| --- | --- |
| 聚焦、选择 | 短促、轻、偏中高频，和强事件拉开音量 |
| 提交、确认 | 上行或稳定的音程，发生时与操作确认对齐 |
| 无效输入 | 短降音或低频敲击，给出原因文本 |
| 木、石、金属或能量冲击 | 按材质改变瞬态、频谱和衰减，方向可作轻声像 |
| 资源和产出 | 小幅亮音，多个事件合并或限频 |
| 危险、完成、失败 | 清楚的频谱与音程差异，只在语义事件上触发 |

音色可以随游戏变化。温暖的经营玩法、紧张的动作玩法和缓慢的探索玩法调整音程、速度、低通与声音密度；它们仍保留清楚的操作确认和稀疏混音。

主题内 `audio.cues` 是可替换、可扩展的默认合成配方。Web 工具包提供包络、扫频、分组音量、低频氛围、限频、声部上限与停止清理。原生引擎可用同类合成或已加载的合法音频素材。策划规定的音乐与音效优先；所有素材在实际运行目录内可解析。

原生引擎也可直接导入包内 `assets/audio/` 的九个 PCM WAV 语义音效。它们由主题配方生成，是默认示例而非固定的全部音色。修改配方后运行 `node scripts/render-audio.mjs` 更新；给项目主题生成音效时传入 `--theme <主题文件> --out <项目音效目录>`。新增配方直接放入 `audio.cues`，名称使用小写字母、数字、短横线或下划线，例如 `gate_open`。清单位于该目录的 `sources.json`。Web 实时合成与 WAV 使用相同的音高和包络配方，具体合成实现不同。

## 解锁、混音与生命周期

第一次真实用户操作触发音频解锁，并等待上下文进入可播放状态，再发出确认音。浏览器阻止播放时显示可操作的启用或静音状态；失败原因被记录，声音不会假装已播放。

音乐与音效分别调节。音效保留瞬态，背景低于关键读数与操作声音。限制声部、高频悬停和连续产出音；重大事件可以短暂降低背景音。静音和音量改变作用于已经在播放的声音。

零音量与静音立即关闭对应增益；非零调整可平滑过渡。检查闲置音效总线设零后的第一次播放，避免延迟处理的渐变让短音漏出。

场景切换、暂停、页面隐藏和卸载都有明确策略：停止、淡出或按策划继续。再次进入不叠加多个背景实例，重复渲染不重复触发同一个音效。一个应用持有自己的音频系统，在生命周期末端释放它。

## 实际检查

在真实浏览器或引擎中点按后试听选择、确认、失败、冲击和背景。确认音量、静音、暂停与返回的行为。可使用 OfflineAudioContext 检查合成结果的峰值、非零信号和声部清理，但这只能证明生成了波形；还要试听混音与声音的情绪。

离线启动也能显示字形并播放必要反馈。验收时检查网络请求、控制台和素材目录，确认没有错误字体、缺失音效、远程占位资源或静音漏网的背景。
