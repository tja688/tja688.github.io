# 对象绘制与可塑性

## 轮廓先于装饰

先在透明背景上画单色剪影，缩到实际游戏尺寸。剪影要表达对象的功能：重型对象用大面积和低重心；侦测对象强调孔洞或指向；容器有口和容量；生物有重心、身体与肢体；建筑有入口和占地关系。相同功能的变体保持家族特征，不同功能改变主要比例或负形。

随后加面内灰阶、统一方向的受光边、一处功能性点彩和少量磨损。对每个主要家族，同时检查单色剪影、默认状态与异常状态。

## 数据化对象蓝图

一个蓝图至少表达以下信息，数据结构按工程选择：

| 字段 | 作用 |
| --- | --- |
| `family` 与 `variant` | 家族与稳定变体，不直接决定游戏能力 |
| `bounds` 与 `pivot` | 美术尺寸和变换中心，与规则碰撞体分别定义 |
| `parts` 与 `anchors` | 可组合的局部零件与连接点，例如主体、探头、轮、舱门、叶片 |
| `material` | 灰阶受光、接缝、颗粒和磨损的生成规则 |
| `accentRole` | 从游戏语义取色，而非按渲染帧随机换色 |
| `stateMarks` | 损伤、禁用、连接、装载、成长或危险的可读标记 |
| `motionProfile` | 重心、准备、动作、恢复、空闲相位等参数 |

定义当前游戏真正需要的轴，不填一套所有字段都为空的万能结构。静态机关可能只有主体与开关，人物则可能需要肢体和朝向。

## 四种可扩展的绘制方式

- **像素蓝图。** 用字符网格表示亮面、阴影、孔洞和点彩。零件独立绘制，按锚点组合。适合角色、标记、资源和小型工具。
- **几何构造。** 由矩形、折线、多边形和环组成，再量化轮廓。适合机器、建筑、管道、航迹和术式。
- **规则铺装。** 按连接、朝向和邻接选择瓦片，接缝与断口依附世界。适合道路、墙、线路与大区域材质。
- **符号加状态。** 清楚的功能符号配合进度、方向和状态标记。适合地图节点、库存、复杂配置与小屏摘要。

Web 工具包提供像素线、圆环、蓝图绘制、种子颗粒与抖动，见 [web-kit.md](web-kit.md)。选择或组合适合对象的方法，不要求所有对象都使用同一种生成器。

## 变化轴和动作

让体型、模块、朝向、资源量、成长与损伤改变有意义的部分。外观变体由固定 ID 与视觉种子稳定生成；空闲动作按实体 ID 错开相位。游戏规则的随机与视觉噪声分开保存。

移动时先确定整体重心，再让局部零件有轻微滞后。准备动作朝即将发生的方向收缩或偏移，结果动作恢复轮廓并呈现状态变化。建筑可以用齿轮、指示灯和进料口动作表达工作；植物可以用叶片张合与成熟标记表达成长。固定建筑的整栋漂浮与人物的整块闪烁都不能代替这些语义动作。

## 可辨认的检查

实际尺寸下，两类主要对象的剪影和负形应可区分。改变一个零件或状态参数，应能产生变体而不改变规则能力和命中范围。颜色撤掉后仍能看出可操作、损伤和重要状态；需要文字才能精确表达的数值，用清晰界面显示。
