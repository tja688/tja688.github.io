# 把技能与策划交给另一个 AI

传入完整 `pixel-ink-game-art` 文件夹或 ZIP，保留 `SKILL.md`、`references/`、`assets/`、`scripts/` 和字体授权文件。再传入游戏策划，以及已有工程或目标平台。技能无需 The Called 仓库才能使用。

可直接使用以下提示词，补充你的文件名与平台要求：

```text
使用 $pixel-ink-game-art。先阅读技能包中的 SKILL.md，再按步骤读取相关参考。
游戏策划案随本消息提供。按照策划实现可玩的游戏，画面、字体、音频和交互反馈采用本技能的语言。
游戏类型、主要对象、状态和操作由策划决定。可以自由设计新的剪影、零件、材质和动画参数。
已有工程沿用现有规则与引擎。若是新项目且没有指定引擎，采用技能中的 Web 默认方案。
通过真实输入检查核心循环、关键页面、字体与声音，修复发现的问题后交付可运行结果和证据。
```

AI 环境不能识别 `$技能名` 时，把首句改为“阅读附件文件夹中的 SKILL.md，并按该文件完成任务”。只粘贴入口而没有附带资源时，字体、绘制工具与完整参考不会自动出现。
